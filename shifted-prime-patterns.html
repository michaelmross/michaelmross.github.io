Shifted prime patterns

Notes from a computational campaign — certified searches, certified absences, and the first lower-bound records.

a, a + P1(p−1), …, a + Pk−1(p−1), p prime

Sources:repository arXiv:2608.19525 blog post

§1The object

A shifted prime pattern is a polynomial progression whose shift parameter is one less than a prime, with the polynomials Pi ∈ ℤ[y] having zero constant term. A theorem of Wooley and Ziegler says these patterns are unavoidable: every set of positive density contains one for infinitely many primes p. The recent paper of Krause, Mousavi, Tao, and Teräväinen makes that quantitative from above, with density bounds that engage only at astronomical scales. These notes work the other side at scales a computer can certify: how far, and at what density, can avoidance actually be pushed?

The repository's harness holds A ⊆ [0, N) as a bitmask, so one prime costs one chain of shift-and-AND operations across the window. A pattern found is a witness; a zero intersection is an exhaustive proof of absence, and that proof — parameters, mask digest, per-prime table — is recorded as a certificate that --verify reproduces byte for byte. Each certificate carries a core digest over the mathematically meaningful content only, stable across schema changes; those are the identifiers quoted throughout these notes.

§2A calibration that bit back

The first structured set we tried looked like a discovery. Take base-8 integers whose digits all lie in {0, 1, 3} and search for square differences (P(y) = y²): 435 of the 550 primes up to 4000 admit no pattern. That is not resistance. The set reduced mod 8 is {0, 1, 3}, no residue there has r + 4 in the set, so no difference is ≡ 4 (mod 8) — and (p−1)² ≡ 4 (mod 8) exactly when p ≡ 3 (mod 4). An entire residue class of primes was blocked before any search ran.

The harness now runs this diagnosis automatically: a residue scan reduces A mod every small modulus and reports which no-pattern verdicts are congruence artifacts. The lesson generalizes — read the scan before calling a null result a finding.

§3The campaign

For the two-point case x, x + (p−1)², blocking every prime p ≤ X means the difference set of A avoids SX = {(p−1)² : p ≤ X} — an instance of Motzkin's difference-avoidance problem. Cantor–Gordon interval sets {n : cn mod m < L} give the classical periodic lower bound; exact circulant independence numbers give more. Every winner below is certified end to end.

Concretely, the X = 10⁵ record means: for every window N up to 10¹⁰, there are explicit sets of density 21/5185 ≈ 0.004 containing no pattern x, x + (p−1)² at all — a regime where the known upper bounds say nothing yet. Across four decades the records track X−1/2 closely (fitted exponent 0.50); under N = X² that is density N−1/4, just above the N−0.267 shape of Ruzsa's square-difference constructions. At every rung the winning conductor sits an order of magnitude below the swept cap, so the exponent looks robust; larger conductors above the caps remain formally possible. One observed regularity: every record conductor factors, beyond its power of two, entirely into primes ≡ 1 (mod 4) — 5·29, 2³·13·37, 5·17·37, 5·17·61.

§4Anatomy of a record

The X = 10⁴ winner is the set {n : 55n mod 3848 < 52}. Its whole proof is one picture: multiply every shift (p−1)² by 55 and reduce mod 3848, and none of the 263 resulting residue classes comes within 52 of zero. The wedge is empty, so no difference of two set elements ever equals a shifted-prime square.

§5Conductors

Sweeping all moduli for the best construction reveals that the landscape is not a scatter of independently good moduli. If the record at m₀ is {n : cn mod m₀ < L}, then at any multiple km₀ the pair (kc, kL) defines literally the same set, so every multiple inherits the record and the plateau is exact. Borrowing the language of Dirichlet characters: plateau members are induced, and the minimal modulus carrying the structure is the conductor. The sweep only ever needs primitive moduli.

§6Open

Three directions, in rough order of expected yield. The conductor sweep now reaches X = 10⁵ (conductor_sweep.py); lifting its caps and explaining the all-primes-≡-1-mod-4 regularity in the record conductors would turn the fitted exponent into a statement. The critical primes make improving each record a concrete re-routing problem — seven at X = 10⁴, nine at 3·10⁴. Exact independence numbers past period ≈ 80 (a proper clique solver) would settle whether the interval family's deficit at X = 30 grows. And the genuine polynomial progressions x, x + (p−1), x + (p−1)² remain untouched: there the Cayley graph becomes a 3-uniform hypergraph, none of these pictures has an analog yet, and the harness is the only certifier available.
